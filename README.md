# 🤖 AI Agent with Google ADK

Built as part of **Google GenAI APAC Academy** program.

## What This Does
An AI agent built using Google's Agent Development Kit (ADK) 
powered by Gemini 2.0 Flash model.

## Tech Stack
- Python 3.14
- Google ADK 2.2.0
- Gemini 2.0 Flash
- FastAPI + Uvicorn

## How to Run
1. Clone this repo
2. Create virtual environment: `python -m venv venv`
3. Activate: `venv\Scripts\activate`
4. Install: `pip install google-adk`
5. Add your API key in `.env` file
6. Run: `adk web`
7. Open: http://localhost:8000
